Numerical Summary

a) Quartiles and the shape of the V1 distribution

The quantile() function can return the first quartile, median and third quartile in a single call.

quantile(sonar$V1, probs = c(0.25, 0.50, 0.75))
    25%     50%     75% 
0.01335 0.02280 0.03555 
# Compare the mean with the median
mean(sonar$V1)
[1] 0.02916394
median(sonar$V1)
[1] 0.0228

The first quartile is 0.01335, the median is 0.02280, and the third quartile is 0.03555. The mean (0.02916) is greater than the median (0.02280), suggesting that the distribution of V1 is right-skewed (positively skewed). In other words, some relatively large values extend the right tail and pull the mean upward.

Write Data to File

First, filter the data to retain only observations in class M. Then use write.csv() to save the filtered data as mine.csv.

mine <- sonar |>
  filter(Class == "M")

write.csv(mine, "../Datasets/mine.csv", row.names = FALSE)

# Check the filtered data
nrow(mine)
[1] 111
unique(mine$Class)
[1] M
Levels: M R

The new dataset contains 111 observations, all belonging to class M. Setting row.names = FALSE prevents R from adding a separate row-number column to the CSV file.
