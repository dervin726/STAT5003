# NSW 公立学校年度入学规模分类

- `headcount.csv`：2004–2025 年逐校学生人数
- `master_dataset.csv`：NSW 公立学校主数据
- `nsw_school_enrolment_analysis_zh.qmd`：中文项目规划与 EDA 报告
- `nsw_school_enrolment_analysis_en.qmd`：英文项目规划与 EDA 报告

报告通过 `School_code` 连接两份官方数据。长表包含 50,336 个学校—年份观测，满足 Large、Messy、Integrated 和 Multi-class。

按要求不预生成 HTML。请在本文件夹中运行 QMD，使相对路径能够找到两份 CSV。
