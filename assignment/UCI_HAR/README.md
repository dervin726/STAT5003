# UCI Smartphone Human Activity Recognition 数据集

- `UCI_HAR_Dataset.zip`：UCI 官方原始数据压缩包
- `har_assignment_analysis.qmd`：英文分析报告源文件
- `har_assignment_analysis.html`：英文分析报告
- `har_assignment_analysis_zh.qmd`：中文分析报告源文件
- `har_assignment_analysis_zh.html`：中文分析报告
- `har_assignment_analysis_files/`：英文 HTML 所需的图表和前端资源
- `har_assignment_analysis_zh_files/`：中文 HTML 所需的图表和前端资源
- `har_assignment_analysis_cache/`：英文报告的 R 计算缓存

请保留 HTML 与对应的 `_files` 文件夹在同一目录中，并在本文件夹中渲染 QMD。
